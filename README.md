# UNO! Coffee — ตารางกะพนักงาน

เว็บจัดตารางกะพนักงาน 23 สาขา เข้าใช้ด้วย **รหัสพนักงาน + PIN**

- **หน้าเว็บ** (ไฟล์ `index.html`) อยู่บน GitHub Pages
- **เซิร์ฟเวอร์และข้อมูล** อยู่ใน Google Sheet ของเจ้าของ ผ่าน Google Apps Script (`apps-script/Code.gs`)

ในหน้าเว็บไม่มีข้อมูลพนักงาน ข้อมูลทั้งหมดดึงจากเซิร์ฟเวอร์หลังเข้าสู่ระบบแล้ว

## ติดตั้ง (ครั้งเดียว)

### 1) ตั้งเซิร์ฟเวอร์บน Google
1. เปิด https://sheets.new เพื่อสร้าง Google Sheet ใหม่ (ไฟล์นี้จะเก็บข้อมูลทั้งหมด)
2. ไปที่เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดจาก `apps-script/Code.gs`
3. แก้บรรทัด `OWNER_PIN = ''` เป็น PIN ของผู้ดูแลหลัก (ตัวเลข 4–8 หลัก) และตรวจว่า `OWNER_EMP` เป็นรหัสพนักงานของผู้ดูแล → กดบันทึก
4. กด **Deploy → New deployment** → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด Deploy แล้วอนุญาตสิทธิ์ตามที่ Google ถาม จากนั้นคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 2) ใส่ลิงก์เซิร์ฟเวอร์ในหน้าเว็บ
แก้ไฟล์ `config.js` ใน repo นี้ (กดรูปดินสอบน GitHub) แล้ววางลิงก์จากขั้นที่ 1:
```js
window.UNO_API_URL = 'https://script.google.com/macros/s/xxxx/exec';
```
กด Commit changes รอประมาณ 1 นาที หน้าเว็บจะอัปเดตเอง

### 3) เข้าใช้ครั้งแรก
1. เปิดหน้าเว็บ แล้วเข้าด้วย `OWNER_EMP` และ `OWNER_PIN`
2. ไปที่ **ตั้งค่า → ผู้ใช้ & สิทธิ์ → นำเข้าข้อมูลสำรอง** แล้วเลือกไฟล์สำรอง (.json) เพื่อย้ายข้อมูลเดิมเข้ามา
3. กด **+ เพิ่มผู้ใช้** ใส่รหัสพนักงาน ตั้ง PIN เลือกสิทธิ์และสาขา แล้วส่งลิงก์เว็บ รหัส และ PIN ให้แต่ละคน

## สิทธิ์
| สิทธิ์ | ทำอะไรได้ |
|---|---|
| Super admin | ดูและแก้ได้ทุกอย่าง รวมหน้าตั้งค่า ผู้ใช้ และการนำเข้า/สำรองข้อมูล |
| Admin | แก้ตารางกะและวันลา เฉพาะสาขาที่ได้รับ |
| ดูอย่างเดียว | ดูได้ แก้ไม่ได้ |

สิทธิ์ตรวจที่เซิร์ฟเวอร์ทุกครั้งที่บันทึก · PIN เก็บแบบเข้ารหัส (ดูย้อนหลังไม่ได้) · ใส่ PIN ผิด 5 ครั้งล็อก 15 นาที · ระบบจำการเข้าสู่ระบบไว้ 30 วัน

## อัปเดตเซิร์ฟเวอร์ภายหลัง
แก้โค้ดใน Apps Script แล้วไปที่ **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ลิงก์ `/exec` จะยังเป็นลิงก์เดิม
